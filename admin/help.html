Content Studio

Edit page copy in English and Arabic, update team members and images, or adjust global typography.

Before your first login

Your administrator must connect GitHub OAuth in Netlify. You need write access to the website repository. Follow CMS-SETUP.md included in the website source.

Publish with confidence

  1. Edit a page, team member or typography setting.
  2. Save a draft.
  3. Wait for Netlify’s preview and check both languages.
  4. Publish when ready. Your website updates after the production build finishes.

Use GitHub file history to restore older content. Keep the latest content and uploaded images when deploying future code updates.
